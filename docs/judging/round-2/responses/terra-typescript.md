# Review

Scores are `[ergonomics, failure, findability, correctness, completeness, clarity]`; Stata has only the first two. Code is schematic where the supplied documentation does not specify the necessary operations. I count the workbook load as part of a read task and repeated per-sheet calls separately. A score of 1 for failure often means that the supplied documentation does not specify the probe, rather than that I have verified a particular runtime error.
