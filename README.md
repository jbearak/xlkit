# xlkit

Read and write Excel `.xlsx` workbooks from R. xlkit complements
[datakit](https://github.com/jbearak/dta-parser): it gives the `import excel`,
`export excel` and `putexcel` lines of a translated do-file one R line each.

Work in progress. See the pull requests for the plan.
